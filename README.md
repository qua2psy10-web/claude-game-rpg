# エルドラシア戦記 (claude-game-rpg)

ドラゴンクエスト風のターン制RPG。素の HTML5 Canvas と JavaScript だけで作られていて、ビルドも依存もありません。

目覚めた魔王を倒すため、戦士サム・魔法使いダリオ・僧侶スンダーの3人が北へ旅します。クリアまでの目安は約1時間です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーを使う場合は次のとおりです。

```bash
python3 -m http.server 8000   # http://localhost:8000/
```

### 操作

| 操作 | キー |
|---|---|
| 移動 / カーソル | 矢印キー(WASD も可) |
| 決定 | Z / Enter / Space |
| キャンセル・メニュー | X / Esc |
| ダッシュ | Shift を押しながら移動 |

- 決定・キャンセル・ダッシュは「せってい」で割り当てを変えられます。
- タッチ端末では、十字パッドと A / B ボタンが自動で出ます。URL に `?touch=1` を付けると強制表示、`?touch=0` で非表示です。
- 迷ったらメニューの「ヘルプ」を開いてください。

## 主な要素

- 街とフィールド: ミルヘイブン村、ハルカ宿場、ダークフォレスト、水晶の洞窟(寄り道のダンジョン)、魔王城
- 戦闘: コマンド式。職業ごとの技、状態異常(毒・スタン・眠り)、形態が変わりサインを出して大技を放つボス
- クリア後: 深淵の迷宮と隠しボス
- 周回: 「つよくてニューゲーム」(レベル・装備・道具を引き継ぎ、敵が強くなる)
- セーブ: 3スロット(1番は従来のセーブと同じ)
- 依頼: 村人からの頼まれごと9件(討伐・届け物・集め物)。メニューの「いらい」で確認できます
- サイコロ屋: ハルカ宿場の小さな運だめし(ゴールドの使い道)
- 鍛冶屋: 武器と防具をゴールドで +5 まで強化(ミルヘイブン村)
- 記録: ずかん(敵図鑑)、きろく(統計と実績)
- 音: 手続きで生成するチップチューンのBGMと効果音(ハルカ宿場と深淵には専用曲)
- 設定: BGM・効果音・環境音の音量、画面のゆれ、ダッシュ

## 開発者向け

```
index.html      入口
css/style.css   スタイル
js/data.js      ゲームデータ(キャラ、敵、道具、マップ、ショップ、実績)
js/main.js      ゲームループ、状態遷移、入力
js/             そのほかの機能(戦闘、マップ、音、ずかん、セーブ枠 など)
tools/          開発用ツール
```

スクリプトは `<script>` タグで順に読み込みます(モジュールなし)。読み込み順は `CLAUDE.md` に書いてあります。

### テストとシミュレーター

Node.js と Playwright が必要です(`node_modules` かグローバルから探します)。

```bash
# 通しテスト(約20秒。終了コード0で全件成功)
NODE_PATH=$(npm root -g) node tools/smoke-test.js

# バランスシミュレーター(本物の戦闘処理で通しプレイを模擬)
node tools/balance-sim.js [回数] [シード]
FULL=1 BOSSLV=12 node tools/balance-sim.js 60 1   # 宝箱・アイテムを使い、Lv12で魔王に挑む
```

敵の能力、技、成長、EXP、ショップの価格を変えたら、シミュレーターを回し直してください。
